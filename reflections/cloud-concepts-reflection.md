# Cloud Concepts Reflection

Cloud computing has become an important part of my daily life because I use many online services for communication, learning, and entertainment. Three cloud services that I regularly use are Google Drive, Facebook Messenger, and Canva. These applications help me complete school tasks, communicate with classmates, and create presentations and other projects more efficiently.

Google Drive is an example of Software as a Service (SaaS) because it allows users to store, manage, and share files through the internet without installing or maintaining servers. It uses the Public Cloud deployment model because the service is available to anyone with a Google account. Facebook Messenger is also a SaaS application because it provides instant messaging, voice calls, and video calls over the internet. Like Google Drive, it uses the Public Cloud model since it is accessible to millions of users worldwide. Canva is another SaaS application that lets users create presentations, posters, and graphic designs using a web browser. It also uses the Public Cloud deployment model because users can access it online from different devices.

Version control is very important in cloud projects because it records every change made to files and allows developers to restore previous versions if mistakes occur. It also helps organize work when multiple people are collaborating on the same project. Git and GitHub make teamwork easier by tracking changes, keeping a complete history of commits, and preventing team members from accidentally overwriting each other's work. Features such as branches and pull requests allow developers to test new ideas before merging them into the main project. By using GitHub, cloud infrastructure and application development become more organized, reliable, and secure. Learning Git and GitHub will help me become more prepared for future IT and cloud computing projects.
