# Cloud Concepts Reflection

Cloud computing is part of my daily life because I use many cloud-based services. Three services I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is a Software as a Service (SaaS) because it allows me to store, access, and share files online without managing servers. It uses the Public Cloud deployment model because it is available to users over the internet.

Facebook Messenger is also a Software as a Service (SaaS). It enables me to communicate with friends and family using the internet. It also uses the Public Cloud deployment model because it serves millions of users online.

Canva is another Software as a Service (SaaS). It allows users to create presentations, posters, and other designs directly in a web browser. Like the others, it uses the Public Cloud deployment model.

Version control is very important in cloud projects because it records every change made to files. If mistakes happen, previous versions can easily be restored. Git and GitHub help teams collaborate by tracking changes, preventing conflicts, and allowing multiple people to work on the same project safely. Using GitHub makes cloud projects more organized, reliable, and easier to manage.
