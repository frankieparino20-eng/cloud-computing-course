Mission Reflection

After doing this mission, I learned more about AWS, Azure, and Google Cloud Platform. Before this activity, I only knew that they were cloud providers, but I learned that they have many different services and each one has its own strengths.

The cloud platform that impressed me the most is Microsoft Azure. I chose Azure because it works well with Microsoft products and services. I also found out that AWS and GCP have many useful services, so I think the best choice still depends on what the company needs.

AWS, Azure, and GCP have some similarities. All of them provide virtual machines, storage, networking, identity management, databases, and other cloud services. They also allow businesses to increase or decrease their resources depending on their needs.

Business requirements are important when choosing a cloud provider. A company should consider its budget, performance, security, scalability, and the technologies it is already using. For example, a company that already uses many Microsoft products may find Azure more convenient. This showed me that the most popular cloud provider is not always the best choice for every company.

By doing this activity, I learned that being a Cloud Solutions Consultant requires comparing different options before making a decision. I learned how to look at the needs of a client and match them with cloud services.

My GitHub Cloud Computing Portfolio also improved because I added research files, comparison tables, recommendations, screenshots, and Linux system information. I also became more familiar with organizing files and writing documentation using Markdown. Overall, this mission helped me understand cloud platforms better and improved my confidence in comparing cloud services.
